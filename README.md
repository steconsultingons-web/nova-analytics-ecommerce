# NovaAnalytics E-commerce Analytics

## Project Overview

NovaAnalytics is an e-commerce analytics project designed to analyze sales performance, customer behavior, product performance, and business opportunities.

## Business Objective

The objective of this project is to help sales managers and business executives monitor business performance and make data-driven decisions.

## Tools

- Python
- Pandas
- Jupyter Notebook
- Power BI
- SQL
- GitHub

## Key Business Questions

- How is revenue evolving over time?
- Which products generate the most revenue?
- Which customer segments are the most valuable?
- Which regions perform best?
- What opportunities exist to improve business performance?

## Project Structure

- `data/` — Dataset
- `notebooks/` — Python analysis
- `sql/` — SQL queries
- `powerbi/` — Power BI dashboard
- `dashboard/` — Dashboard screenshots
- `documentation/` — Project methodology
